# Systemics

A unified, AI-augmented competitive leaderboard for tracking developer progress across GitHub, LeetCode, HackerRank, and Codeforces. 

## Features
- Unified Data Engine aggregating metrics from multiple coding platforms
- Tech-Tree Progression System
- AI-powered Skill Radar & Weekly Post-Mortems 
- Real-time Activity Feed

## Tech Stack
- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS
- Supabase (PostgreSQL)
- Clerk (Authentication)
- Groq via Vercel AI SDK
- Pusher (WebSockets)
